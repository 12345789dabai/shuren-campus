# 树人校园数字孪生系统

> **浙江树人学院 期中作业** · 数字孪生交互系统

基于 Three.js 构建的校园三维数字孪生系统，可在浏览器中实时运行。使用 Claude Code 等 AI 工具辅助开发，腾讯混元3D 生成部分模型资产。

## 功能特性

- 🏫 **三维校园场景** — 7栋建筑（图书馆、教学楼、宿舍、食堂、体育馆、行政楼）、道路网络、树木灌木、中心雕塑
- 🖱 **交互控制** — 鼠标左键旋转、滚轮缩放、右键平移、点击建筑查看信息
- 👁 **视角切换** — 透视、鸟瞰、图书馆特写、校门特写 4 种视角
- 🎚 **图层控制** — 建筑/道路/植被独立显示开关
- 🚶 **自动漫游** — 沿预设路径环游校园，速度可调
- 🌓 **昼夜切换** — 一键切换白天/夜晚光照模式

## 技术栈

- **前端框架**: HTML5 + JavaScript (ES Modules)
- **3D引擎**: Three.js (^0.170.0)
- **构建工具**: Vite
- **AI工具**: Claude Code（架构/逻辑）, 腾讯混元3D（模型生成）
- **3D模型**: GLB 格式（混元3D + 程序化备用几何体）

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 项目结构

```
shuren-campus/
├── index.html              # 入口页面
├── package.json            # 依赖配置
├── vite.config.js          # Vite 配置
├── public/models/          # AI 生成模型（GLB）
└── src/
    ├── main.js             # 入口逻辑
    ├── scene.js            # 场景/相机/渲染器
    ├── campus.js           # 校园场景构建
    ├── controls.js         # 视角控制 + 漫游
    ├── interaction.js      # 点击交互 + 弹窗
    ├── lighting.js         # 光照 + 昼夜切换
    ├── layers.js           # 图层管理
    ├── modelLoader.js      # GLB模型加载
    ├── data.js             # 建筑配置数据
    └── style.css           # UI样式
```
